## 三、個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

桌遊整理後的串列有 4 筆資料（`['amy', 'ben', 'amy', 'cora']`），是因為 `'amy'` 出現了兩次；但依活動規則，同一人在同一場活動重複報名只算一位參加者且只收一次費用，去重後實際參加桌遊的人只有 3 位（`amy`、`ben`、`cora`），因此費用以 `3 × 120 = 360.00` 元計算。

- **直接拆成 `list`**：**保留**了原始填報的先後順序與重複次數，適合用來查看原始報名紀錄；但**失去**了「不重複名單」的乾淨集合特性，若直接用長度算錢會重複收費。
- **再轉成 `set`**：**保留**了不重複的元素集合，方便做交集、聯集與差集比較；但**失去**了原本的排列順序與重複出現的次數。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三中，設桌遊去重集合為 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影去重集合為 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，兩者完全相同，因此交集 $B \cap M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$（共同人數 3 人），聯集 $B \cup M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$（總不重複人數 3 人）。

- **為什麼是 6 人次**：「報名人次」是兩場活動各自去重後的人數相加（$|B| + |M|$），因為這 3 位參加者兩場都報了名，每人各算 1 人次，所以是 $3 + 3 = 6$ 人次。
- **為什麼總應收仍是 600 元**：兩場活動各自依不重複人數乘上單價計算，桌遊應收為 $3 \times 120 = 360$ 元，電影應收為 $3 \times 80 = 240$ 元，兩場合計為 $360 + 240 = 600$ 元。
